# Staff-hour sensitivity — Bassam

Animated COMP857 presentation, packaged for Streamlit Community Cloud.

## Deploy
- Repository: `rewanebrahembadr-cmyk/COMP857-Production-Explorer`
- Branch: `main`
- Main file path: `bassam_presentation/app.py`
- Python: 3.12

The adjacent requirements.txt supplies this app’s only dependency. No solver, licence, API key or secret is needed: the charts illustrate the group’s analytical piecewise solution.

## Controls
Previous / Next navigate, Replay animation repeats the current slide, and Full screen expands the presentation where allowed by the browser. Keyboard arrows and R also work after clicking inside the presentation. The charts animate automatically on entry; this version does not contain a staff-hour slider.

## Local use
Run `streamlit run bassam_presentation/app.py` from the repository root, or open index.html directly. Google Fonts are optional; fallback fonts work without them.

This companion does not replace the individually narrated assessment video.
